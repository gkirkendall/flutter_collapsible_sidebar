## [3.0.0] - 2026-07-21

- **Flutter 3 Upgrade**: Modernized Dart SDK constraints (`>=3.0.0 <4.0.0`) and core Flutter package dependencies.
- **Android V2 Embedding & Gradle Upgrade**: Modernized Gradle build setup and Java versions for Android platform compatibility.
- **FlexColorScheme Integration**: Added `AppTheme` helpers (`lib/color_theme.dart`) for Material 3 light/dark mode theme support powered by `flex_color_scheme`.
- **Multi-Platform Support**: Added support for macOS, Linux, and Windows desktop apps alongside Web, iOS, and Android.
- **Layout & Overflow Fixes**: Resolved `RenderFlex` overflow issues in `CollapsibleItemWidget` for long item labels.
- **Example App Improvements**: Upgraded example app with Material 3 styling and modern Cupertino icons.
